# TITAN 智慧路燈：海報素材包

所有素材都從作品 3D 模型直接渲染，造型和配色與原作一致。除了主視覺之外都是透明背景。

| 資料夾 | 內容 | 格式 | 尺寸 |
|---|---|---|---|
| 01_main_visual | 主視覺：白天、夜晚 | PNG | A2 直式 300dpi（4961×7016） |
| 02_titan_pole | TITAN 路燈去背：3/4 視角、側視 | PNG + SVG | 約 2200×4000 px |
| 03_titan_annotated | 路燈標註圖（8 個元件）：淺底用、深底用 | PNG + SVG | 5160×4980 px |
| 04_vehicles | 汽車 6 色＋側視、機車 4 色＋側視、公車 2 色＋側視 | PNG + SVG | 長邊 1800–3000 px |
| 05_people | 行人 6 款（含長者、警員） | PNG + SVG | 985×1600 px |
| 06_city | 城市模型：純街景、完整場景（車、人、路燈），各有白天與夜晚 | PNG | 6438×3523 px |

## 使用說明
- **PNG**：高解析點陣圖，直接放進 Canva、PowerPoint、Photoshop 即可。
- **SVG**：向量圖，可以無限放大，也能在 Illustrator、Figma、Inkscape 裡改顏色。
  - 標註圖 SVG 的文字是可編輯的文字物件，字型為 Noto Sans TC（沒有安裝時會用系統的中文字型）。
  - 路燈 SVG 上的 LED 看板文字和公車路線看板是內嵌的小點陣圖，其餘都是向量色塊。
  - SVG 用平面著色，金屬質感比 PNG 略淡。
- **主視覺**上方留了天空空間，可以放標題。
- **主視覺和城市模型沒有 SVG**：場景裡有建築窗戶貼圖、光影和半透明掃描光錐，轉成向量會失真，建議用 PNG（解析度已足夠 A2 印刷）。
