## 使用說明
- **PNG**：高解析點陣圖，直接放進 Canva、PowerPoint、Photoshop 即可。
- **SVG**：向量圖，可以無限放大，也能在 Illustrator、Figma、Inkscape 裡改顏色。
  - 標註圖 SVG 的文字是可編輯的文字物件，字型為 Noto Sans TC（沒有安裝時會用系統的中文字型）。
  - 路燈 SVG 上的 LED 看板文字和公車路線看板是內嵌的小點陣圖，其餘都是向量色塊。
  - SVG 用平面著色，金屬質感比 PNG 略淡。
- **主視覺**上方留了天空空間，可以放標題。
- **主視覺和城市模型沒有 SVG**：場景裡有建築窗戶貼圖、光影和半透明掃描光錐，轉成向量會失真，建議用 PNG（解析度已足夠 A2 印刷）。

## AI 辨識圖說明
- 偵測框沿用原作的 3D 立體線框，顏色代表狀態：青色＝偵測中、綠色＝已改善、橘色＝提醒中、紅橘色＝警示、琥珀色＝停讓／穿越中。
- 標籤卡的文字照原作。SVG 裡的標籤文字可以直接編輯，偵測框、軌跡線、行人光圈都是獨立的向量圖層（`ai-box-front`、`ai-box-back`、`ai-trail`、`ai-ring`、`ai-label`）。
- 標籤裡的符號（💡 ⚠ ✓）是 emoji。有些軟體（例如 Illustrator）不支援彩色 emoji，會顯示成單色或空白，到時可以刪掉或換成圖示。
- 情境圖是從模擬中挑出的真實時刻，畫面中的提醒都是系統當下的判斷。
